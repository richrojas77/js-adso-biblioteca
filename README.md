# 📚 Biblioteca Aurora

## Descripción
Biblioteca Aurora es una página web diseñada para facilitar la búsqueda y el alquiler de libros. Los usuarios pueden explorar diferentes categorías, conocer los libros disponibles y encontrar nuevas opciones de lectura. Su objetivo es ofrecer una experiencia sencilla y accesible para los amantes de la lectura.

## 🛠️ Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript
- Bootstrap
